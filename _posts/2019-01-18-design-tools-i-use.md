ကုဒ်ရေးတယ်ဆိုပေမယ့် Wireframing ဖန်တီးတာ၊ နမူနာဒီဇိုင်းတွေ ဆွဲပြရတဲ့ အခြေအနေမျိုးလည်း ရှိတတ်ပါတယ်။ ဒီတော့ Wireframing နဲ့ Prototyping အတွက် လိုအပ်တဲ့ Tools တွေကို အကျွမ်းတဝင်ရှိနေမှသာ မြန်မြန်ခရီးတွင်မယ်လို့ ခံယူထားပါတယ်။

## Inkscape

Website အတွက် Wireframing ဆွဲတဲ့အခါ [Inkscape](https://inkscape.org/) ကို စပြီးသုံးဖြစ်တယ်။ နောက်တော့ Blog တွေရေးတဲ့အခါ ကိုယ်ပိုင် feature image လေးတွေ သုံးချင်တော့ Inkscape နဲ့ ဖန်တီးဖြစ်တယ်။ Inkscape သုံးပြီး Minimalist Style သရုပ်ဖော်ပုံလေးတွေ ဆွဲတတ်ချင်တယ်။ လက်ရှိမှာလည်း အားရင်အားသလို လေ့လာနေဆဲပါပဲ။

## GIMP

YouTube Channel အတွက် Thumbnails တွေ ဖန်တီးတဲ့အခါမှာ ဓာတ်ပုံတွေကို တည်းဖြတ်ဖို့ လိုအပ်တာကြောင့် [GIMP](https://www.gimp.org/) ကို ရွေးချယ်သုံးဖြစ်တယ်။ အရင်ကတော့ Adobe Photoshop CS 5 သုံးဖူးတယ်။ ဒါပေမယ့် ဝယ်သုံးဖို့ကျတော့ လက်လှမ်းမမှီပြန်ဘူး။ Crack Version တွေ ကျတော့လည်း မသုံးသင့်ဘူးလို့ ခံယူထားတယ်။ ဒါကြောင့် Open-source Software တွေဘက် လှည့်ဖြစ်ပါတယ်။

## RawTherapee

နောက်တစ်ခုကတော့ [RawTherapee](https://www.rawtherapee.com/) ဖြစ်ပါတယ်။ Adobe Lightroom အစားထိုး Open-source software တစ်ခုပါပဲ။ မိုဘိုင်းဖုန်းနဲ့ ဆိုရင်တော့ ကိုယ်ရိုက်ပြီးသားဓာတ်ပုံတွေကို တည်းဖြတ်ချင်ရင် [Snapseed](https://snapseed.online/) သုံးတယ်။ ကွန်ပြူတာနဲ့ ဆိုရင်တော့ RawTherapee ကို သုံးပါတယ်။

---

တကယ်တော့ Inkscape၊ GIMP နဲ့ RawTherapee တို့ထက် ပိုပြီးသုံးရလွယ်ကူတဲ့ Software တွေ၊ Application တွေ တော်တော်များများ ရှိပြီးသားပါ။

ဥပမာ — [Canva](https://www.canva.com/)၊ [Figma](https://www.figma.com/) တို့ဆိုရင် အခမဲ့သုံးလို့ရသလို Cloud ကို အခြေခံတာကြောင့် ပိုပြီးတော့ အဆင်ပြေပါတယ်။ အချိန်မရွေး၊ နေရာမရွေး အသုံးပြုလို့ရတယ်။ အင်တာနက်နဲ့ စမတ်ဖုန်းတစ်လုံး ရှိတာနဲ့တင် အရမ်းအဆင်ပြေပါတယ်။ 

ဒါပေမယ့် ကိုယ်နေတဲ့နေရာက အင်တာနက်ဒေတာ စျေးကြီးလွန်းနေမယ်၊ လျှပ်စီးမီးကလည်း မမှန် ဖြစ်နေရင်တော့ Cloud Software တွေသုံးတာထက် ဒီလို Offline သုံးလို့ရတဲ့ Open-source software တွေက ပိုပြီးသင့်လျော်ပါတယ်။
